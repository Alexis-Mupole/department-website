Computing Programs at Bugema University

Our department offers a range of accredited programs designed to prepare students for successful careers in the technology industry.

Bachelor of Science in Information Technology (BSc. IT)

Most Popular

Duration: 4 Years (8 Semesters)

The BSc. in Information Technology program provides comprehensive knowledge in software development, computer networks, database management, and IT project management. Students gain practical skills through hands-on projects and industrial attachments.

Career Opportunities:

  • Software Developer
  • Network Administrator
  • Database Administrator
  • IT Project Manager
  • Systems Analyst
  • Web Developer

Core Subjects:

Programming Database Systems Computer Networks Web Development IT Project Management Cybersecurity

Bachelor of Science in Computer Science (BSc. CS)

Duration: 4 Years (8 Semesters)

The Computer Science program focuses on computational theory, algorithms, software development, artificial intelligence, and machine learning. Ideal for students interested in research and advanced computing technologies.

Career Opportunities:

  • Software Engineer
  • AI/ML Engineer
  • Data Scientist
  • Research Scientist
  • Systems Programmer
  • Game Developer

Core Subjects:

Data Structures Algorithms Artificial Intelligence Machine Learning Operating Systems Computational Theory

Bachelor of Science in Software Engineering (BSc. SE)

Duration: 4 Years (8 Semesters)

The Software Engineering program teaches students to design, develop, and maintain software systems using industry-standard methodologies. Emphasizes agile development, software architecture, and quality assurance.

Career Opportunities:

  • Software Engineer
  • Full Stack Developer
  • QA Engineer
  • DevOps Engineer
  • Software Architect
  • Technical Lead

Core Subjects:

Software Design Agile Development Quality Assurance Software Architecture DevOps Mobile Development

Diploma in Information Technology

Fast Track

Duration: 2 Years (4 Semesters)

A comprehensive diploma program providing foundational skills in computing and IT. Perfect for those seeking quick entry into the job market or wishing to upgrade to a degree.

Career Opportunities:

  • IT Support Specialist
  • Web Designer
  • Junior Developer
  • Network Technician
  • Technical Support

Core Subjects:

Computer Fundamentals Programming Basics Web Design Networking Basics Database Concepts

Certificate in Web Development

Duration: 6 Months

A short-term certificate program focused on modern web development technologies. Students learn to create responsive websites and web applications.

Career Opportunities:

  • Frontend Developer
  • Web Designer
  • WordPress Developer
  • Junior Web Developer

Core Subjects:

HTML/CSS JavaScript Responsive Design WordPress

Admission Requirements

Bachelor's Programs

  • Uganda Certificate of Education (UCE) with at least 5 passes
  • Uganda Advanced Certificate of Education (UACE) with at least 2 principal passes
  • Mathematics at O-Level is required for BSc. CS
  • English Language proficiency

Diploma Program

  • UCE certificate with at least 5 passes
  • Relevant certificate or experience may be considered

Certificate Program

  • UCE certificate
  • Basic computer knowledge
  • Interest in web development
