Program Overview

The BSc. Network Systems Administration program prepares students to design, implement, and manage enterprise network infrastructure. This program focuses on building the technical expertise needed to ensure seamless connectivity and network security in modern organizations.

Students gain hands-on experience with routers, switches, servers, and cloud platforms, preparing them for careers in network administration and systems management.

Core Subjects

Network Design Server Administration Cloud Computing Network Security Virtualization Wireless Networks

Curriculum Overview

What you'll learn throughout the program

Year 1

Semester 1

Computer Fundamentals, Introduction to Programming, Mathematics I, Communication Skills, Physics

Semester 2

Data Structures, Office Applications, Electronics, Introduction to Networks, Mathematics II

Year 2

Semester 1

Network Fundamentals, Operating Systems, Computer Architecture, Statistics, Database Basics

Semester 2

LAN Implementation, Windows Server Administration, Linux Administration, Network Cabling

Year 3

Semester 1

WAN Technologies, Network Security, Virtualization, Cloud Computing Fundamentals

Semester 2

Wireless Networks, Server Administration, Firewalls, Research Methods

Year 4

Semester 1

Advanced Network Design, Network Monitoring, VoIP, Elective I

Semester 2

Final Year Project, Network Management, IT Ethics, Industry Attachment

Admission Requirements

Direct Entry (A-Level)

  • UCE with at least 5 passes
  • UACE with at least 2 principal passes
  • English and Mathematics recommended
  • Physics is an added advantage

Mature Age Entry

  • At least 25 years of age
  • Passed mature age entrance examination
  • Relevant work experience in IT
